# Bosnia 2026 trip site

One self-contained page: `index.html`. No build step, no dependencies to install. Photos load from Wikimedia Commons and the Fraunces font from Google Fonts, so the page needs an internet connection to show those; everything else works offline.

## Make it live on GitHub Pages

1. Create a new repository on github.com (for example `bosnia-2026`). Public is required for free Pages.
2. Upload both files from this folder: `index.html` and `README.md`. Commit to `main`.
3. In the repository, open Settings, then Pages. Under Build and deployment choose Source: Deploy from a branch, Branch: `main`, folder `/ (root)`. Save.
4. Wait a minute or two. The site appears at `https://YOURUSERNAME.github.io/bosnia-2026/`.

To update the site later, edit or re-upload `index.html` and commit. Pages redeploys automatically.

## Notes

- Google ratings and review counts were pulled in September 2026 and are baked into the page. The Maps and reviews button on each card opens the live Google listing.
- Drive times marked with a wave are added up from the planner's own leg times; unmarked times are the planner's wording.
